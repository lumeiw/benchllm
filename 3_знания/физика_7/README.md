# ИС ОЗЯМ-ФОП · часть 3 · Знания · срез «Физика, 7 класс»

Первый срез, в котором узлы графа наполнены знаниями. На нём проверяется весь цикл «граф → знания → задания → тест LLM» до того, как наполнять граф целиком.

## Что в срезе

- **148 понятий**: 136 впервые названы в элементах 7 класса, 12 есть только в пунктах ОГЭ, но по содержанию относятся к темам 7 класса (давление, деформация, момент силы, условие плавания и др.; список и основания — `автоматизация/ручные_данные/физика_7/доп_понятия.json`).
- 45 элементов, 5 разделов, 19 умений ФОП 7 класса; 203 связи между понятиями среза.
- Срез пересобран 25.10.2026 по текущему графу. Раньше в нём было 149 понятий: в графе слиты дубли, и «Условие равновесия рычага» стало другим названием понятия «Правило равновесия рычага». Его знание (M₁ = M₂) перенесено к «Правилу равновесия рычага».
- **Вес понятия** — доля учебного времени 7 класса: часы элемента делятся между его понятиями (main — 2, part — 1). Сумма весов — 100 %. У элементов 3.12 и 4.10 в базовом плане 0 часов, поэтому у их понятий (подшипник, плавание рыб, влияние атмосферного давления) вес 0.

## Источник знаний — «Библиотека ЦОК»

С 1 июня 2026 года поддержка РЭШ приостановлена, поэтому основной источник — «Библиотека ЦОК» (academy-content.apkpro.ru) Минпросвещения.

- `источники/цок_физика_7.json` — выгрузка всех 111 уроков физики 7 класса: тесты с ключами и решениями, текстовые страницы, интерактивные материалы, субтитры видео. Опорные конспекты-картинки не выгружались.
- `источники/цок_корпус.jsonl` — та же выгрузка, нарезанная на 4 938 текстовых единиц с номером урока и ссылкой. Номер единицы (`CK…`) — хэш её текста, поэтому он не меняется при повторной выгрузке.

Как получена выгрузка: под учётной записью ЦОК в браузере запрашиваются данные урока (`/_next/data/<build>/ru/lesson/<uid>.json`) и файлы материалов из хранилища: `specification.xml` — тесты, `content/*/N.xml` — страницы, `structure.json` — интерактивы, `*.vtt` — субтитры. Тексты извлекаются в самом браузере, наружу уходит один JSON. Скрипт для других классов — `автоматизация/этапы/бенчмарк/цок_выгрузка.js`.

## Знания

`решения/знания.json` — знания по понятиям: школьная формулировка и подтверждение к ней (в пилоте их составил Claude, в конвейере — модель на этапе `знания_llm`). Этап `знания` проверяет каждую цитату (она должна быть точной подстрокой источника) и собирает `знания.jsonl`. Рядом — `кандидаты.json`: предложения корпуса, которые модель получает для каждого понятия.

| | |
|---|---|
| фрагментов знаний | 236, у всех 148 понятий есть хотя бы один |
| виды | определение 74, закономерность 42, ход опыта 21, свойство 20, пример 18, единица 11, принцип действия 11, вывод 11, формулировка закона 10, формула 6 и др. |
| статус | подтверждено 188 · частично (часть текста без цитаты) 34 · без источника 12 · ошибка источника 2 |
| цитаты | ЦОК — 296 (из 81 урока), кодификатор ОГЭ — 11, ФОП — 4 |

Поля записи: `id`, `concept_id`, `concept`, `ctype`, `element`, `kind`, `text` (эталон), `status`, `note`, `sources` (тип, урок, ссылка, цитата).

**Без источника (на вычитку), 12:** определения механического движения, трения, равнодействующей, электрических явлений и объяснения явления; способы уменьшения и увеличения давления; передача давления твёрдыми телами; причина выталкивающей силы; закон изменения механической энергии; ход опытов со свинцовыми цилиндрами и с определением скорости; заблуждение «в невесомости нет силы тяжести» (служит дистрактором). В ЦОК этот материал либо в картинках-конспектах, либо его нет.

**Ошибки, найденные в ЦОК** (используются в заданиях на поиск недостоверной информации, ФОП 1.16):
- урок 52: формулировка закона Паскаля подписана как «Формулировка закона Архимеда»;
- урок 20: «плотность жидкости равна 900 г/см³» (по смыслу 900 кг/м³);
- урок 14: «Атом — мельчайшая частица вещества» (в школьном курсе так называют молекулу).

## Прочие файлы

- `формулы.json` — 18 формул в форме 7 класса (A = F·s без cos α, p = ρgh без p₀), обозначения и единицы; источник каждой — пункт кодификатора ОГЭ или ЦОК. Три формы помечены «подтвердить»: P = mg, R = F₁ + F₂, F₂/F₁ = S₂/S₁.
- Справочные данные для расчётных заданий (g = 10 Н/кг, плотности веществ, как в справочных таблицах КИМ ОГЭ) — `автоматизация/ручные_данные/физика_7/справочные_данные.json`. **Сверить с актуальной демоверсией ФИПИ.**

## Пересборка

Файлы этой папки строит конвейер `автоматизация/` (конфиг `конфиги/физика_7.json`, этапы с `срез` по `знания`):

```bash
cd автоматизация
python3 run.py конфиги/физика_7.json --llm replay   # вместо модели — решения из решения/знания.json
python3 сравнить.py прогоны/физика_7 ..              # результат совпадает с этой папкой
```

Результат прогона лежит в `автоматизация/прогоны/физика_7/`. Папку проекта конвейер не меняет: чтобы обновить её, скопируйте файлы оттуда.
