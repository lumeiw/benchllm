# ИС ОЗЯМ-ФОП · часть 3 · Знания

Наполнение узлов графа (часть 2) содержанием: определения, факты, формулы, даты, примеры. Каждый фрагмент хранится вместе с источником.

План:
1. **Запрос из графа.** Для каждого понятия строится запрос: понятие + синонимы + элемент + класс + раздел/эпоха.
2. **Источники по приоритету:**
   - РЭШ и открытый банк заданий ФИПИ (школьный уровень, задания с ответами и кодами кодификатора);
   - ЦОК по ссылкам из поурочного плана Конструктора — нужен вход, автоматически не собирается;
   - энциклопедии — только для фактов: даты, имена.
3. **Привязка.** Фрагмент → понятие, с источником, цитатой и уверенностью, как evidence в K12-KGraph.
4. **Проверка.** Выборочная вычитка и согласие с предметником.

Статус: пилот сделан — срез «Физика, 7 класс» (`физика_7/`): 148 понятий, 236 фрагментов знаний с цитатами. С 1 июня 2026 года РЭШ не поддерживается, поэтому основной источник — «Библиотека ЦОК» (все 111 уроков физики 7 класса выгружены). Срез строится конвейером `автоматизация/` (конфиг `конфиги/физика/физика_7.json`).

Второй срез — «Физика, 8 класс» (`физика_8/`): 171 понятие, 594 фрагмента знаний, 22 найденные ошибки ЦОК, 23 формулы. Источник — все 105 уроков физики 8 класса в ЦОК. Срез собран тем же конвейером (конфиг `конфиги/физика/физика_8.json`, знания составлены в режиме `--llm manual`) и воспроизводится режимом replay. Задания по 8 классу готовы: `4_бенчмарк/физика_8/` (1340 заданий).

Третий срез — «Физика, 9 класс» (`физика_9/`): 202 понятия, 617 фрагментов знаний, 13 найденных ошибок ЦОК, 49 формул. Источник — все 154 урока физики 9 класса в ЦОК. Собран так же, как 8 класс (конфиг `конфиги/физика/физика_9.json`, режим `--llm manual`), и воспроизводится режимом replay. Задания: `4_бенчмарк/физика_9/` (1618 заданий).

История 5–11 классов: конвейер настроен (конфиги `конфиги/история/история_5.json` … `история_11.json`, свои виды знаний и промпты — раздел «Бенчмарк по истории» в `автоматизация/README.md`).
