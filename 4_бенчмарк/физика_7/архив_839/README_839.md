**Правильный ответ по построению.** В заданиях из графа ответ — само ребро. В неверных вариантах — понятия, не связанные с верным ни в графе, ни по смыслу: исключены виды и роды, понятия с общей формулой и близкие пары из списка `автоматизация/ручные_данные/физика_7/близкие_пары.json`. В S1 неверные варианты — понятия, которые опираются на данное: они не могут быть его предпосылками, потому что граф без циклов. Задание, в тексте вопроса которого есть ответ, при сборке выбрасывается.

**Что составлено LLM.** Это файл `решения/задания_llm.json` (по разделам программы): 74 типичные ошибки (ложные утверждения с объяснением), 31 ситуация «что за явление», 29 вопросов «почему…» с ключевыми пунктами, по 3 неверные формулировки для 8 законов, 25 отдельных заданий: графики, перевод словесной формулировки в формулу, ошибки в материалах ЦОК, техника безопасности, практическое применение. В пилоте этот материал составил Claude, в конвейере его пишет модель на этапе `задания_llm`. Нужна выборочная вычитка.

## Поля задания (`задания.jsonl`)

`id` (`T.<срез>.<семейство>.<ключ>`), `family`, `track` (содержание/структура), `requirement` (код умения ФОП 7 кл.) и его текст, `concepts` (первое — главное), `element`, `section`, `exam_items`, `question`, `options` [{key, text}], `format`, `answer`, `check` (как проверять), `explanation`, `steps`, `status`, `basis` (ребро графа, id знаний, id формулы или шаблона), `weight`, `concept_weight_pct`.

Типы проверки (`check.type`):
- `choice` — совпадение набора ключей («24»);
- `sequence` — точный порядок;
- `number` — число в указанной единице с относительным допуском `rel_tol` (обычно 1 %);
- `value_error` — значение и погрешность;
- `text` — одно из допустимых слов;
- `rubric` — эталон и ключевые пункты, оценивает проверяющий (LLM-судья или человек).

**Вес задания** — по часам программы (итерация 3): вес главного понятия делится поровну между его заданиями внутри дорожки. Сумма весов по дорожке — 1. Невзвешенный балл считается как обычно.

## Пересборка и проверка

Файлы этой папки строит конвейер `автоматизация/` (конфиг `конфиги/физика_7.json`, этапы с `формулы_llm` по `итог`). Этап `итог` проверяет набор: структуру, ключи, повторы, подсказки в вопросе, веса.

```bash
cd автоматизация
python3 run.py конфиги/физика_7.json --llm replay   # вместо модели — решения пилота
python3 сравнить.py прогоны/физика_7 ..              # результат совпадает с этой папкой
```

Сборка детерминирована: варианты перемешиваются с зерном от id задания. Изменили знания, формулы или `решения/задания_llm.json` — пересоберите, остальное подтянется само. Шаблоны расчётных заданий — `автоматизация/ручные_данные/физика_7/шаблоны_расчёт.py`.

Этап `дистракторы_llm` (модель-проверяющий ищет спорные неверные варианты) на пилоте не запускался: в replay прошлых решений нет. При прогоне с моделью такие задания получат статус «… · варианты под вопросом».
