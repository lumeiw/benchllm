## Что составлено LLM

Все решения LLM в этом срезе составил Claude в режиме `--llm manual`: запросы конвейера лежат в `автоматизация/прогоны/физика_8/llm/запросы/`, ответы — в `.../llm/ответы/`. Итоговые решения части 4 — папка `решения/`:

- `решения/задания_llm.json` — материал по двум разделам программы: 93 типичные ошибки (ложные утверждения с объяснением), 16 ситуаций «что за явление», 16 вопросов «почему…» с ключевыми пунктами, по 3 неверные формулировки для 9 законов, 12 отдельных заданий (графики, формула по словесной формулировке, ошибки в материалах ЦОК, техника безопасности). Нужна выборочная вычитка.
- `решения/цепочки_роли.json` — разметка 38 формул (21 формула 8 класса и 17 формул 7 класса). Для каждой величины указан объект (тело, жидкость, топливо, участок цепи, резисторы), понятие, единица и правдоподобный диапазон значений. Для процессов записаны условия задачи: «вся подведённая теплота идёт на нагревание тела», «топливо сгорает полностью», «резисторы соединены последовательно» и т. п. Одна формула исключена: F.specific_heat повторяет Q = c·m·Δt.
- `решения/цепочки.json` — решения по наборам формул для задач C2. Из 298 наборов 40 не дали правдоподобных чисел. Из остальных 258 приняты 92, отклонены 166, у каждого отклонения записана причина. Правила отбора:
  - **принимаются:**
    - электрические наборы одного участка цепи без скрытой переопределённости данных;
    - закон Джоуля — Ленца вместе с нагреванием, плавлением или парообразованием;
    - сгорание топлива вместе с нагреванием, плавлением или парообразованием;
    - двухшаговые наборы из определений (заряд, сила тока, работа, мощность).
  - **отклоняются:**
    - наборы, где данные противоречат скрытому закону: проверка рангом якобиана ловит лишнее данное, связанное с остальными законом Ома или равенством Q = A для резистора;
    - смешанные последовательное и параллельное соединения;
    - сопротивление вместе с правилами соединений;
    - плотность вместе с тепловыми формулами (в них смешиваются вещества);
    - КПД теплового двигателя: значения КПД получались неправдоподобными (0,04–0,86);
    - механика вместе с теплотой;
    - два тепловых процесса подряд;
    - сгорание вместе с законом Джоуля — Ленца;
    - трёхшаговые наборы только из определений.
- `решения/дистракторы.json` — проверка неверных вариантов в 668 тестовых заданиях дорожки «содержание». Помечено 15 заданий: K9 — 4, G3, G3r, G4, G5 — по 2, K1 — 2, K2 — 1. В них неверный вариант можно защитить как тоже верный, например опыт Эрстеда в вопросе о действии тока на магнитную стрелку или амперметр в работе по КПД нагревателя. Эти задания получили статус «авто · варианты под вопросом». Ключ ни в одном задании неверным не признан.

## Поля задания (`задания.jsonl`)

Те же, что в срезе 7 класса: `id` (`T.<срез>.<семейство>.<ключ>`), `family`, `track` (содержание/структура), `requirement` (код умения ФОП 8 кл.) и его текст, `concepts` (первое — главное), `element`, `section`, `exam_items`, `question`, `options` [{key, text}], `format`, `answer`, `check` (как проверять), `explanation`, `steps`, `status`, `basis` (ребро графа, id знаний, id формулы, шаблона или цепочки), `weight`, `concept_weight_pct`. У помеченных при проверке вариантов есть ещё `distractor_check` (спорные ключи и комментарий).

В `basis` задания C2: `chain` (id цепочки), `group` (набор формул), `formulas`, `scheme` (ход решения от искомой величины к данным), `norm` и `reference_data`.

Типы проверки (`check.type`): `choice` — 716, `number` — 449, `rubric` — 134, `sequence` — 26, `value_error` — 9, `text` — 6. Описание типов — в README среза 7 класса.

**Вес задания** — по часам программы: вес главного понятия делится поровну между его заданиями внутри дорожки. Сумма весов по дорожке — 1.

## Пересборка и проверка

Файлы этой папки строит конвейер `автоматизация/` (конфиг `конфиги/физика/физика_8.json`). Решения LLM подключены как replay, поэтому пересборка идёт без модели:

```bash
cd автоматизация
pip install sympy                                    # нужен этапу «цепочки»
python3 run.py конфиги/физика/физика_8.json --llm replay    # вместо модели — решения из решения/ и 3_знания/физика_8/
python3 сравнить.py прогоны/физика_8 ..               # результат совпадает с этой папкой (6 из 6 файлов)
```

Сборка детерминирована: варианты перемешиваются с зерном от id задания, перебор цепочек не зависит от PYTHONHASHSEED. Ручные данные среза лежат в `автоматизация/ручные_данные/физика/физика_8/`:

- `шаблоны_расчёт.py` — 64 шаблона C/M/I/R;
- `справочные_данные.json` — таблицы ОГЭ 2026;
- `близкие_пары.json`;
- `цепочки.json` — ручные уточнения понятий и единиц для величин формул, общих с 7 классом (ρ, P, A, R, E и т. п.).

Формулы 7 класса для цепочек подключены в конфиге полем `формулы_прошлых_классов`.

Этап `итог` проверил набор: 1340 заданий, ошибок 0, предупреждений 0.
