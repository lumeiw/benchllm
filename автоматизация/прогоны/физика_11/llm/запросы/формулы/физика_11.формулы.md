# Система

Ты составляешь справочник формул, обозначений и единиц для одного класса школьной физики. По нему потом программа автоматически строит задания: «какой формулой выражается величина», «выразите величину из формулы», «в каких единицах измеряется», «какой буквой обозначают».

## Вход

`{"классы": […], "понятия": [...], "все_названия": [...]}`. У понятия: `название`, `тип` (величина, закон, …), `знания` — уже проверенные знания о нём (определения, формулы, единицы), `формулы_кодификатора` — формулы из кодификатора ОГЭ в LaTeX.

## Что записать

1. `формулы` — формулы, которые изучаются **в этом классе**, в той форме, в какой их пишут в учебнике этого класса (в 7 классе A = F·s без cos α; давление столба жидкости p = ρ·g·h без p₀). Каждая формула:
   - `id` — `F.` + короткое латинское имя (`F.density`);
   - `concepts` — названия понятий из `все_названия`, к которым формула относится (первое — главное);
   - `text` — запись в одну строку: умножение — `·`, деление — ` / `, индексы — юникодом (`F₁`, `Eп`);
   - `kind`: `div` — вида `a = b / c`; `mul` — вида `a = b·c` или `a = b·c·d`; `other` — всё прочее;
   - `parts` — для div и mul: символы по порядку `[a, b, c(, d)]`; для other — `[]`;
   - для `other` — `неверные`: три правдоподобные, но неверные записи той же формулы (перепутанные множители, лишний квадрат и т. п.);
   - `source` — откуда формула: «кодификатор ОГЭ <пункт>» или «знания: <понятие>»; `note` — оговорка о границах применимости, если нужна.
2. `величины` — каждый символ из `parts`: `{"ρ": {"name": "плотность", "unit": "кг/м³"}}`.
3. `обозначения` — `{название понятия: буква}` для величин, у которых в школьном курсе есть устойчивое обозначение.
4. `единицы` — `{название понятия: единица СИ}` для всех величин класса (в т. ч. частных: «Сила тяжести» — «Н»).
5. `единицы_через_основные` — 3–6 производных единиц класса через другие единицы СИ: `{"unit": "Па", "is": "Н/м²", "quantity": "давление", "понятие": "Давление"}`.

Названия понятий — только из `все_названия`, дословно. Единицы — по ГОСТ 8.417-2002 («Единицы величин»).

## Ответ

Только JSON: `{"величины": {…}, "формулы": […], "единицы_через_основные": […], "обозначения": {…}, "единицы": {…}}`.
