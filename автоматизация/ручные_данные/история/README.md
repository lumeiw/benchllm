# Ручные данные бенчмарка истории

Для истории не обязательны: конвейер работает без них. Если понадобятся, папка на класс — `история_<N>/` (путь задан в
`конфиги/история/история_<N>.json`, ключ `ручные_данные`):

- `близкие_пары.json` — пары понятий, которые нельзя ставить неверным вариантом друг к другу: `[["Минин", "Пожарский"], …]`;
- `поиск_синонимы.json` — дополнительные слова для поиска кандидатов в корпусе ЦОК: `{"Ледовое побоище": [["чудск", "озер"]]}`;
- `доп_понятия.json` — понятия, которые есть только в пунктах кодификатора, но относятся к темам класса (как у физики).

Формул, шаблонов расчёта и цепочек у истории нет.
